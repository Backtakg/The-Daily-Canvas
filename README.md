# The Daily Canvas

A calm, minimal drawing space. No accounts, no sign-up, no external libraries.

## Features

- Draw with a mouse, finger, or stylus
- Brush, eraser, color palette, custom color, and brush-size control
- Undo and redo
- Clear the page
- Export your artwork as a PNG
- Automatically saves the current drawing in this browser on this device
- Responsive layout for phones, tablets, and desktops

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. GitHub will publish the site at the Pages URL shown in that section.

This first version is intentionally browser-only. Drawings are stored in the visitor's own browser and are not shared between different visitors or devices. Shared live drawing would require a small backend, which can be added later without introducing user accounts.

## Keyboard shortcuts

- `B`: brush
- `E`: eraser
- `Ctrl/Cmd + Z`: undo
- `Ctrl/Cmd + Shift + Z` or `Ctrl/Cmd + Y`: redo
